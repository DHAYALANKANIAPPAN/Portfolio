## 🌐 Overview & Philosophy

Welcome to my personal portfolio repository!

Unlike conventional frontend design portfolios filled with generic UI templates, this portfolio is built to **visually showcase real infrastructure, systems engineering, network protocols, and DevOps automation**.

It features a **dual-mode architecture**:
1. **Standalone Zero-Dependency Static Engine** (`index.html`, `style.css`, `script.js`): Ultra-fast, zero build dependencies, works right out of the box in any browser or static host.
2. **Modern Next.js 14 Stack** (`src/`): Built with React 18, TypeScript, Tailwind CSS, Framer Motion, and Lenis smooth scrolling.

## ⚡ Visual DevOps Command Center & Systems Lab

This portfolio includes interactive, production-grade simulations demonstrating real systems chops:

- 📊 **Multi-Node Cluster Telemetry & Health HUD**: Live simulated telemetry across 4 cluster nodes (`ingress-gateway`, `telemetry-worker`, `database-replica`, `aws-runner`) with dynamic CPU jitter, ping latencies, and port mappings.
- 🚀 **Interactive CI/CD Deployment Pipeline Simulator**: Run a full GitOps deployment workflow (`Git Push` ➔ `Trivy CVE & Lint` ➔ `Pytest Suite` ➔ `Docker Multi-Stage Build` ➔ `Ansible Fleet Deploy` ➔ `Zero-Downtime Health Check`) with real-time stdout logs streaming in an embedded terminal.
- 📡 **Z-Protocol 16-Byte Wire Packet Inspector**: Interactive bitmask toggles for `SYN`, `ACK`, `FIN`, `RST`, and `PSH` flags showing how custom Layer-4 binary frames and state machines are parsed on raw Python sockets.
- 🔒 **ONey P2P Tunneling Architecture**: Visual topology illustrating direct UDP hole-punching and AES-256-GCM encrypted remote system control without third-party cloud relays.
- 💻 **In-Browser Terminal Shell**: Interactive bash terminal supporting commands: `whoami`, `docker ps`, `ansible`, `zprotocol`, `oney`, `uptime`, `uname -a`, `matrix`, `clear`.

## 🚀 Running the Portfolio Locally

### Option 1: Instant Static Preview (No Node.js Required)
Simply open `index.html` in any web browser, or use Python's built-in web server:
```bash
python3 -m http.server 3000
```
Then visit `http://localhost:3000`.

### Option 2: Next.js Modern Stack
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
Open `http://localhost:3000` to view the Next.js application.
